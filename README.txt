REALSITE PAYLOAD 3.88 BLOG FILES

1. Copy payload.config.ts to the project root.
2. Copy src/collections into your project's src/collections.
3. Copy src/app/(payload) into your project's src/app.
4. In tsconfig.json add this path alias:
   "@payload-config": ["./payload.config.ts"]
5. Wrap your EXISTING next.config.ts with withPayload from @payloadcms/next/withPayload. Do not replace your existing Next config options.
6. Make sure .env.local contains DATABASE_URL and PAYLOAD_SECRET.
7. Run:
   npx payload generate:importmap
8. Run:
   npm run dev
9. Open http://localhost:3000/admin

IMPORTANT: importMap.js is generated by Payload and is intentionally not included.
